# Code of conduct

In issues, reviews and other project spaces:

- Treat people respectfully and welcome different experience levels.
- Critique code and claims with evidence; avoid personal attacks or harassment.
- Respect privacy and consent. Do not post private information or credentials.
- Keep contributions relevant, constructive and free of threats or discrimination.
- Accept reasonable moderation and give others room to correct mistakes.

The maintainer, [@codingleo](https://github.com/codingleo), may clarify expectations,
edit or remove harmful content, close disruptive discussions, or restrict repeated
abuse. Decisions should consider context and be explained when doing so is safe.
There is no guaranteed response time or confidentiality promise for public posts.

For a non-sensitive concern, contact the maintainer through an issue. For a
sensitive concern, ask for a private channel without disclosing details publicly;
no private project contact is currently published. If the concern involves the
maintainer, use GitHub's platform reporting options where appropriate. See
[GitHub's abuse-reporting guidance](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines#reporting-abuse).
