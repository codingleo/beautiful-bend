# Support

Search [existing issues](https://github.com/codingleo/beautiful-bend/issues) first.
For a reproducible problem or a focused improvement, open an issue using the
available templates. Usage questions can use a blank issue. Include the repository
commit, Bend generation/version, relevant source, commands and actual results;
remove credentials, private data and unrelated output.

This project teaches Bend and validates its own fixtures. Compiler problems should
be minimized against the pinned upstream toolchain before reporting to
[bendlang/bend](https://github.com/bendlang/bend/issues). Keep a local issue when
our guidance or fixtures also need correction. Do not send security-sensitive
material to a public issue; follow [SECURITY.md](SECURITY.md).

[@codingleo](https://github.com/codingleo) is the current maintainer. This is a
community project with no promised response SLA, commercial support or guaranteed
support for untested hosts/backends. GitHub Issues is enabled; this guidance does
not depend on Discussions or a private chat channel being available.
