# Maintainers

The repository owner and current maintainer is [@codingleo](https://github.com/codingleo).
The [CODEOWNERS file](.github/CODEOWNERS) routes reviews to that account. It does
not itself require approval or establish a response-time commitment.

The maintainer reviews scope, laws/oracles, attribution and compatibility;
triages public issues; and decides releases and repository settings. Contributions
are welcome through pull requests. Maintainer-authored changes still need an
independent review path if required-review rules are enabled; the owner should
choose additional trusted reviewers or an explicitly documented exception policy.
Do not add an unknown reviewer merely to make a rule satisfiable.

Use [SUPPORT.md](SUPPORT.md) for questions, [SECURITY.md](SECURITY.md) for sensitive
findings, and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.
Settings and release decisions are listed in the
[maintainer checklist](docs/MAINTAINER_CHECKLIST.md) and [release guide](docs/RELEASING.md).
