# Fresh Astra evaluation — duplicate readings

On 2026-10-24 a fresh **gpt-6-astra**, high-reasoning agent received the updated
skill and a new law-preserving repair task. The prompt and rubric are recorded
as `duplicate-readings` in [cases.json](../cases.json); the rubric, repository
fixtures, authoring findings and earlier outputs were withheld from the agent.
It could read a standalone skill snapshot and the pinned upstream source.
It had no inherited authoring conversation and was instructed not to read this
repository. This is one observed use, not a controlled model-effectiveness study.

## Input and specification integrity

The [input project](../inputs/duplicate-readings/LAWS.bend) supplied a one-copy
implementation, an unfinished proof, and a law relating output length to a
recursive twice-length specification. The law was written before the agent ran.
Input and output LAWS SHA256 both equal
`5c47c65e1795e3ec874a19611fce08fb73966ebc779b91c451beba95ba7ba15a`.

The task asks for two adjacent copies of each Nat reading, preserving order.
The supplied law states doubled length only. The agent correctly identified
that payload/order requirements need additional laws for universal coverage.
It did not edit the contract to conceal that distinction.

## Reproduction and limits

From this result's `duplicate-readings/` directory with Bend 2.0.39 and Node:

```sh
bend PROOF.bend --check-only
bend PROOF.bend
bend main.bend --check-only
bend main.bend -o /tmp/duplicate-readings.js
node /tmp/duplicate-readings.js
```

Compare stdout with the exact block above. For the negative check, copy the
project to a temporary directory, replace `h <> h <> duplicate(t)` with
`h <> duplicate(t)` in that copy only, retain identical LAWS, and require a
proof rejection. Never mutate the successful record in place.

No kernel check was attempted because the prior filesystem/Lean blocker remains.
No baseline without the skill, repeated trials, native/GPU run or broad agent
benefit claim is supplied. These artifacts are outside the 100-case corpus. The
four authoring partitions used agents with access to expectations; their compiler
results are fixture development evidence, not fresh guidance evaluations.
